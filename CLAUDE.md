## What This Is

Personal website for Steve Macenski (steve.macenski.com), built with Hugo using a custom theme called `macenski`. Deployed to GitHub Pages via GitHub Actions on push to `main`.

## Build & Development Commands

- **Local dev server:** `hugo server` (live reload at localhost:1313)
- **Production build:** `hugo --gc --minify`
- **Hugo version in CI:** 0.147.6 (extended edition)

## Architecture

- **Hugo config:** `hugo.toml` — site params, menu structure (Projects, Publications, Recognitions, Robots, About, Contact)
- **Custom theme:** `themes/macenski/` — no third-party theme; all layouts and CSS are in-repo
  - `layouts/index.html` — homepage template
  - `layouts/_default/baseof.html` — base HTML shell (iA Writer Mono font, cache-busted CSS)
  - `layouts/partials/` — nav, header, footer
  - Section-specific layouts: `layouts/{about,awards,contact,projects,publications,robots-collage}/list.html`
  - Single stylesheet: `themes/macenski/static/css/style.css`
- **Content:** `content/` — each section has an `_index.md` with frontmatter and inline HTML/Markdown
- **Static assets:** `static/images/` — headshot, robot photos, woodworking photos, project images
- **CNAME:** `static/CNAME` → `www.steve.macenski.com`
- **`public/`** is the build output directory (generated by `hugo`)

## Key Details

- Goldmark renderer has `unsafe = true` enabled, so content files use raw HTML freely
- CSS is cache-busted via `?v={{ now.Unix }}` query param in baseof.html
- The contact form submits via a Google Apps Script backend (see `GOOGLE_APPS_SCRIPT_SETUP.md`)
- No JavaScript build toolchain — all JS is inline in templates/content
- No `data/`, `assets/`, or `i18n/` directories are used
